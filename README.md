# Recipe Booklet

Turn recipe PDFs saved from websites into a booklet you can print and fold.

**Open it:** https://distillerypi.github.io/recipe-booklet/

- **iPhone / iPad:** open the link in Safari → Share → **Add to Home Screen**. It then works offline.
- **Windows / Mac:** open the link in Chrome or Edge. To install it as an app, click the install icon in the address bar.

Everything happens in your browser. Recipes are never uploaded anywhere.

Printing a booklet: double-sided, **flip on short edge**, actual size (100%). Then fold the stack in half.
